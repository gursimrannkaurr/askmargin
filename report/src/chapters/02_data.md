# Chapter 2 | Tools and Libraries Used

- **Platform:** Google Colab with Python.
- **PyMuPDF:** reads the text of PDF files page by page.
- **NLTK:** splits text into sentences.
- **scikit-learn:** TF-IDF word-matching search.
- **sentence-transformers (all-MiniLM-L6-v2):** turns text into vectors (embeddings) for meaning-based search.
- **Transformers (FLAN-T5-base):** small open language model that writes the answer.

**Data:** four public arXiv papers (Attention Is All You Need, BERT, RAG, Sentence-BERT), 61 pages in total, and 10 test questions with known answers.

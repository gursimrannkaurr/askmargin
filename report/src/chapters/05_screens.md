# Chapter 5 | Web Demo

## 5.1 The live demo

The same idea is available as a website at **askmargin.vercel.app**. It uses the same embedding model and a similar refusal rule, and it runs inside the browser, so a PDF that a user drops into the page stays on their computer. The website answers in a simpler way than the notebook: it shows the best matching sentences with their page numbers and scores, and it does not run FLAN-T5.
